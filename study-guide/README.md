# חבילת קטלוג L3VEL3 לשיתוף

התיקייה מוכנה להעלאה כפי שהיא לשרת או שירות אחסון סטטי התומך ב-HTTPS.

## קובץ פתיחה
`index.html`

## תצוגה מקדימה לוואטסאפ
`share-preview.jpg`

כדי שוואטסאפ יציג תמונה, כותרת ותיאור, יש לשלוח קישור ציבורי מסוג HTTPS.
לאחר העלאת התיקייה, יש לשלוח את כתובת `index.html` או את כתובת התיקייה.

אם שירות האחסון אינו תומך בכתובות יחסיות לתמונת Open Graph, החליפו בקובץ
`index.html` את `share-preview.jpg` בכתובת HTTPS המלאה של התמונה.
